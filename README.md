# Structured Language Reasoning (SLR) V0.2

A transparent, non-LLM language reasoning experiment with ontology, SPO relations, semantic validation, and dynamic memory.

## Run

```bash
python -m src.main
```

Try:

- The cat eats the mouse.
- What does the cat eat?
- Who eats the mouse?
- The cat does not eat the mouse.

V0.2 focuses on turning language into validated facts stored in dynamic memory.
